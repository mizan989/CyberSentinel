How It Works

Scan Workflow
  1. You choose an approved demonstration target and a scan profile.
  2. The target is checked against a hard-coded allowlist — anything else is rejected.
  3. Nmap runs host discovery and service/version detection.
  4. Results are parsed into structured data (open ports, services, versions, OS guess).
  5. Each detected service is checked against a small offline CVE lookup table.
  6. A 0–100 risk score is calculated from the severities found.
  7. Everything is saved to the database and rendered as an HTML + downloadable PDF report.
Responsible Use

CyberSentinel is a portfolio / educational project. It does not exploit anything — it only performs read-only discovery and reporting, and only against hosts that have explicitly opted in to being scanned for demonstration purposes (such as scanme.nmap.org, which Nmap's own maintainers provide for exactly this kind of testing).

Scanning systems you don't own or have explicit written authorization to test is illegal in most jurisdictions. If you deploy this project, keep the allowlist in config.py restricted to targets you are authorized to scan.
