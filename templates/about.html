Architecture & Methodology

Overview of CyberSentinel's scanning pipeline, safety controls, and technological foundations.

End-to-End Audit Pipeline
Phase 1 Target Allowlist Check

Validates destination against hardcoded portfolio demonstration targets (e.g. scanme.nmap.org, localhost) or private RFC-1918 subnets.

Phase 2 Nmap Discovery Engine

Executes asynchronous background Nmap scans for TCP port discovery, service version banner grabbing, and OS fingerprinting.

Phase 3 Offline CVE Correlation

Parses service banners against a curated offline vulnerability dataset, matching affected software versions without external runtime network dependencies.

Phase 4 Risk Scoring & PDF Build

Computes a 0–100 composite risk score and dynamically compiles technical HTML dashboards alongside downloadable ReportLab PDF reports.

Responsible Security Research & Ethics

CyberSentinel is strictly an educational portfolio project. It performs non-intrusive, read-only discovery and signature correlation. It contains no exploitation modules or brute-force tooling.

Legal Boundary: Scanning networks or computer systems without explicit, prior written authorization from the system owner is illegal under cybercrime legislation worldwide.
